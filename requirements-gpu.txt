# 知途 · 运行依赖（GPU 环境，迁移到有显卡的机器时用这份）

与 requirements.txt 的唯一区别是 torch 换成 CUDA 版。
**代码一行都不用改**：ml/config.py 里的 resolve_device() 会自动探测到 CUDA 并切到 gpu 档位。

## 安装步骤（目标机器）

```bash
# 1) 建虚拟环境
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS

# 2) 先装 CUDA 版 torch（按目标机器的 CUDA 版本选一条）
pip install torch --index-url https://download.pytorch.org/whl/cu121      # CUDA 12.1
pip install torch --index-url https://download.pytorch.org/whl/cu124      # CUDA 12.4
pip install torch --index-url https://download.pytorch.org/whl/cu126      # CUDA 12.6

# 3) 再装其余依赖（不会覆盖 torch）
pip install -r requirements.txt

# 4) 验证
python -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```

看到 `True` 和设备名即成功。

## 切到大规模档位

```bash
set ZT_PROFILE=gpu            # Windows CMD
$env:ZT_PROFILE="gpu"         # PowerShell
export ZT_PROFILE=gpu         # bash

# 或者每次显式指定
python -m ml.data.build_dataset --profile gpu
python -m ml.run_experiments --profile gpu
```

档位差异（见 ml/config.py）：

| 档位 | 学生数 | 序列长度上限 | batch | epochs | d_model | 说明 |
|------|--------|--------------|-------|--------|---------|------|
| cpu  | 800    | 100          | 32    | 60     | 48      | 无显卡，分钟级出结果 |
| gpu  | 4000   | 200          | 128   | 120    | 128     | 有显卡，指标更稳 |

数据规模放大后指标会更稳，模型之间的差异也更容易看出来。

> **`max_seq_len` 不是随便设的**：它同时决定数据集截断长度和 DKT/SAKT 能看多少步，
> 两者必须一致（否则 BKT 在全长上评测、神经网络只看前 `max_len` 步，不可比，见 README 第七节第 8 条）。
> 切到 gpu 档后用真实数据集要显式对齐：
> `--max-seq-len 200`。
